# 💸 Expense Tracker v1.7

A simple terminal-based Expense Tracker built using Python. It helps users manage their budget by recording income and expenses, tracking transactions, editing or deleting history, and monitoring their remaining balance.

> 📱 Built entirely on an Android phone before owning a laptop.

---

# ✨ Features

- 💰 Set an initial budget
- ➕ Add income
- ➖ Add expenses
- 📂 Expense categories
- 📜 Transaction history
- ✏️ Edit previous transactions
- 🗑️ Delete transactions
- 💾 Save balance to a file
- 🖥️ Beginner-friendly terminal application

---

# 🛠️ Technologies Used

- Python 3.x
- File Handling
- Functions
- Lists
- Loops
- Conditional Statements

# 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/Braincells-org/Braince.expence.git
```

### 2. Open the project folder

```bash
cd expense-tracker
```

### 3. Run the project

```bash
python main.py
```
